# Katkı Rehberi / Contributing

## Türkçe

1. Issue açarak değişikliği anlatın.
2. Ayrı bir branch kullanın.
3. `npm test`, `npm run build` ve mümkünse `npm run test:rules` çalıştırın.
4. Gerçek personel, kart UID'si, Firebase projesi veya şifre içermediğini kontrol edin.
5. Pull request içinde donanım değişiklikleri için bağlantı şeması ve güvenlik etkisini açıklayın.

## English

1. Open an issue describing the change.
2. Work on a separate branch.
3. Run `npm test`, `npm run build` and, when possible, `npm run test:rules`.
4. Verify that no real employee data, card UID, Firebase project or password is included.
5. For hardware changes, document the wiring and safety impact in the pull request.
