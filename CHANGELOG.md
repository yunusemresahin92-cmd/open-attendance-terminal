# Changelog

## 0.4.1 — Public edition

- Created a clean company-neutral public repository.
- Removed production Firebase configuration, private release scripts and company branding.
- Added build-time Firebase configuration through `.env.local`.
- Added Turkish and English documentation.
- Added generic application/brand artwork.
- Retained USB and Wi-Fi RFID terminal support.
- Retained persistent offline queue, stale-read protection and Firestore rule tests.
- Buzzer remains optional and can be assembled later with the documented protected driver stage.

Earlier internal version notes are intentionally not included because they referred to a private deployment.
